# Delivery 360

Este repositório é uma apresentação pública e demonstrativa do Delivery 360, uma solução da Rico Soluções Inteligentes para transformar dados de delivery em inteligência gerencial para restaurantes.

Ele é separado dos aplicativos privados de origem. Não contém código, dados, exports, credenciais, logs ou capturas reais de clientes. Os números e nomes exibidos nos assets são fictícios e servem apenas para comunicar a experiência e a capacidade do produto.
